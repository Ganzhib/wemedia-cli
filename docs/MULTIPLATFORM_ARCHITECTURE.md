# wm 多平台发布设计

wm 面向 AI Agent 提供统一的自媒体内容管理能力。用户安装并登录目标平台后，AI 调用 CLI 准备内容、保存草稿、发表和核对结果；平台后台操作由驱动完成。

## 产品契约

用户只操作登录与平台强制身份验证。浏览器、上传、排版、封面及常规后台表单由 CLI 管理。普通使用不要求提取 Cookie、配置开发者密钥或启动独立引擎服务。

每个目标分别记录实际执行阶段。草稿保存、提交受理、审核与最终展示各有证据；写入结果未知时先回查，不自动重发，也不为模拟跨平台回滚而删除其他平台的内容。

## 平台抽象

平台 ID、能力、内容产物及资源种类通过注册定义扩展。核心不包含具体平台名称、平台参数或发布流程特例。驱动选择、内容约束、后台操作及观察结果归一化由平台实现负责。

公共核心负责账号身份、不可变内容、发布计划、操作记录、去重、锁和恢复。一个平台可以直接发布，另一个可以先保存草稿；执行器依据工作流依赖运行，不预设共同的后台路径。

## 单一入口

CLI 命令和 Skill 名称统一为 wm。平台资料按需引用，当前能力通过 platform list、platform capabilities 和 schema 发现。安装包不分发独立平台 Skill 或绘图 Skill。

新契约直接替换旧结构，不增加旧命令别名、旧任务 schema 读取器或自动迁移层。保留仍被当前功能调用的底层实现，删除被替代的封装。
